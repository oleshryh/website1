# Словарь: что означают слова

Короткие объяснения терминов, которые встречаются в переписке с Claude.

**Репозиторий (repo)** — папка проекта со всей историей изменений.

**Коммит** — сохранение состояния проекта с подписью «что изменилось». Как точка
сохранения в игре: к ней всегда можно вернуться.

**Ветка (branch)** — параллельная линия сохранений. Позволяет делать
незаконченную работу, не ломая рабочую версию. В этом проекте основная ветка
называется `main`.

**Мердж (merge)** — объединить ветку с основной.

**Push / pull** — отправить сохранения на GitHub / забрать их оттуда.

**Откат (revert)** — отменить изменение новым сохранением, не стирая историю.

**Сборка (build)** — превращение исходников в готовые файлы сайта (папка `dist`).
Если сборка не проходит — сайт не работает.

**Линтер (lint)** — автоматическая проверка кода на ошибки и небрежности.

**Деплой (deploy)** — выкладывание собранного сайта в интернет, чтобы он был
доступен по адресу. Сейчас в проекте не настроен.

**Дев-сервер (`npm run dev`)** — локальная версия сайта на твоём компьютере,
видна только тебе.

**Компонент** — кусок страницы в отдельном файле: шапка, экран, окно с видео.

**Хук (hook)** — маленькая функция, которая добавляет компоненту поведение,
например «следить за прокруткой».

**Прогресс прокрутки (scroll progress)** — число от 0 до 1: 0 — начало сцены,
1 — конец. Все анимации на сайте привязаны к нему.

**Кадры (frames)** — картинки анимации солдата, лежат в `public/frames*`.

**Ассеты (assets)** — картинки, видео, шрифты — всё, что не код.

**Зависимость (dependency)** — сторонняя библиотека, которую использует проект.

**Бэкенд** — серверная часть, куда отправляются данные форм. В проекте пока нет.
