# Документация проекта Site1

Сайт-одностраничник ATMARAKSI: VR-тренажёры для военной подготовки.
Экраны сменяются не переходами по страницам, а прокруткой одной длинной «сцены».

## С чего начать

| Файл | О чём |
| --- | --- |
| [architecture.md](architecture.md) | Как устроена страница: сцена, экраны, анимация солдата, все файлы `src/` |
| [content-editing.md](content-editing.md) | Где менять тексты, товары, картинки, цвета, ссылки |
| [frames-pipeline.md](frames-pipeline.md) | Как из видео получаются кадры анимации |
| [workflow.md](workflow.md) | Порядок работы: коммиты, ветки, проверка, откат |
| [glossary.md](glossary.md) | Словарь: коммит, ветка, сборка, деплой — простыми словами |

## Быстрый старт

```bash
npm install     # один раз после клонирования
npm run dev     # сайт на http://localhost:5173
npm run check   # линтер + сборка, перед каждым коммитом
```

## Что важно знать сразу

- Формы на сайте пока никуда не отправляют данные — бэкенда нет.
- Ссылки в шапке и в соцсетях частично заглушки (`href="#"`).
- Видео в модалке «Watch demo» — временный ролик с YouTube.
- Переключатель языка UA/EN сейчас только визуальный, переводов нет.
