# Кадры анимации: из видео в картинки

Солдат на сайте — это папка с картинками, которые пролистываются прокруткой.
Картинки делает скрипт `scripts/process-video.mjs` из видео в папке `media/`.

## Что делает скрипт

1. Разбирает видео на кадры (через встроенный ffmpeg).
2. Вырезает белый фон и делает его прозрачным.
3. Обрезает всё лишнее и кладёт все кадры на **один общий холст**, чтобы фигура
   не прыгала от кадра к кадру.
4. Сохраняет в `.webp` — это лёгкий формат для веба.

## Как запустить

```bash
node scripts/process-video.mjs media/video1.mp4 public/frames
```

Полезные ключи:

| Ключ | Зачем |
| --- | --- |
| `--canvas 765x472` | Задать тот же холст, что и у первого клипа — чтобы второй клип стыковался с первым без скачка размера |
| `--step 2` | Взять каждый второй кадр — лёгкий набор для телефонов |
| `--width 800` | Ширина итоговой картинки в пикселях |

Размер холста первого клипа скрипт печатает в консоль при запуске — его и нужно
передавать в `--canvas` для второго клипа.

## Готовые наборы

| Папка | Что это | Кадров |
| --- | --- | --- |
| `public/frames/` | Основной клип, экраны 1–2 | 102 |
| `public/frames-turn/` | Разворот в профиль, экран 3 | 102 |

Промежуточные PNG складываются в `.frame-cache/` — эту папку можно спокойно
удалять, она не входит в проект.

## Если поменялось количество кадров

Число кадров прописано в коде: `FRAME_COUNT` в `src/components/SoldierScrollFigure.jsx`.
После перегенерации набора это число нужно поправить, иначе анимация оборвётся
раньше времени или застынет в конце.

## Важно про вес

Каждый набор — около 4–5 МБ. Они лежат прямо в репозитории, потому что это часть
сайта. Не читай и не листай эти папки при работе — это сотни файлов.
