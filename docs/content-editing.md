## Товары

Всё в одном месте — `src/data/products.js`. Один товар = один блок:

```js
{
  slug: 'rpg-7-grenade-launcher-shooting-simulator',  // адрес страницы товара
  name: 'RPG-7 Training',                             // название
  description: 'Master the RPG-7 launcher safely.',   // описание
  image: '/products/rpg-7.jpg',                       // картинка
}
```

Добавить товар — добавить такой блок в список. Он сам появится и в списке на
третьем экране, и в выпадающем меню шапки.

Поменять фотографию — положить свой файл в `public/products/` **с тем же
именем**, что указано в `image`. Ничего в коде править не нужно. Сверху на фото
всегда накладывается зелёный оттенок, чтобы карточки смотрелись одинаково.

## Цвета и шрифт

`src/index.css`, блок `@theme` в самом верху:

```css
--color-canvas: #eeeeec;  /* фон страницы */
--color-ink: #141412;     /* основной текст */
--color-muted: #78776f;   /* серый текст */
```

Меняешь три значения — меняется весь сайт.

## Анимация и тайминги

- Сколько крутить до следующего экрана — `src/components/stage.js`.
- Скорость автоперелёта между экранами — `useScrollAutoAdvance.js`,
  `MS_PER_VIEWPORT`.
- Насколько нужно крутить колесо, стоя на экране, чтобы страница поехала дальше
  (мёртвая зона) — `WHEEL_THRESHOLD` там же. Пауза после перелёта, пока
  накрутка не считается, — `COOLDOWN_MS`.
- Сколько страница должна постоять неподвижно, прежде чем сама доедет до
  ближайшего экрана, — `SETTLE_MS`.
- Где появляется и исчезает текст экрана — числа в `useScrollFade(...)` внутри
  самого экрана: пара `[0.42, 0.55]` означает «начать проявляться на 42%
  прокрутки экрана, полностью появиться на 55%».
- Насколько солдат отъезжает вправо на третьем экране — `LANE_3` в
  `SoldierScrollFigure.jsx`.
