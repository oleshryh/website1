## Два языка (EN / UA)

Каждый текст на сайте записан парой: `{ en: '…', ua: '…' }`. Переключатель
UA/EN в шапке меняет язык всего сайта сразу и запоминает выбор в браузере.
По умолчанию — английский.

- Общие слова (пункты меню, «Talk To Sales», «View Demo») — `src/data/copy.js`.
- Товары — `src/data/products.js`, отзывы — `src/data/clients.js`.
- Остальные тексты — прямо в файле своего блока, рядом с английским.

Поменять перевод — найти английскую фразу поиском и поправить `ua:` рядом.
Перевод сделан Claude; военные термины стоит показать носителю языка.

Украинские фразы длиннее английских. Кнопки первого экрана подобраны так,
чтобы стоять в одну строку: «Зв’язатися» и «Демо-відео». Если удлинить их,
«Демо-відео» уедет на следующую строку.

## Товары

Всё в одном месте — `src/data/products.js`. Один товар = один блок:

```js
{
  slug: 'rpg-7-grenade-launcher-shooting-simulator', // адрес страницы товара
  number: '02',                                      // номер на карточке
  title: 'RPG-7',                                    // название
  tagline: 'Master RPG-7 launcher safety',           // строка в меню шапки
  cardLine: 'Master RPG-7 launcher safety',          // строка на карточке
  art: [{ src: '/products/cards/rpg-7.png', x: 23, y: 43, w: 261, h: 131 }],
  notes: [{ text: '// launcher simulation', x: 204, y: 43, w: 87 }],
}
```

`art` — картинки на карточке, `notes` — мелкие подписи рядом с ними. Числа —
положение в пикселях внутри области картинки 295×220, как в Figma.

Добавить товар — добавить такой блок в список. Он сам появится и в карточках на
главной, и в выпадающем меню шапки.

Поменять картинку — выгрузить её из Figma в 2× и положить в
`public/products/cards/` **с тем же именем**, что указано в `src`.

## Цвета и шрифт

`src/index.css`, блок `@theme` в самом верху:

```css
--color-canvas: #eeeeec;  /* фон страницы */
--color-ink: #141412;     /* основной текст */
--color-muted: #78776f;   /* серый текст */
```

Меняешь три значения — меняется весь сайт.

## Анимация и тайминги

- Длительность поворота солдата — `TURN_SECONDS` в `src/components/stage.js`
  (сейчас 3 секунды; быстрее начнут пропускаться кадры). Разгон и торможение —
  мягкая кривая `EASE_IN_OUT_SINE` в `useStageTurn.js`.
- Сколько второй экран держится на месте — `PINNED_VH` там же.
- Прокрутку сайт не перехватывает: поворот запускается и доигрывается сам,
  а страница едет, как её крутят.
- Где появляется и исчезает текст экрана — числа в `useScrollFade(...)` внутри
  самого экрана: пара `[0.13, 0.26]` означает «начать проявляться, когда солдат
  повернулся на 13%, полностью появиться на 26%».
- Размер солдата на первом экране — `heroLayout.js`, функция `natural`: `2/3`
  высоты окна, но не шире `0.45` её ширины. Ширины колонки с текстом — `COPY_WIDE`
  и `COPY_SIDE` там же.
